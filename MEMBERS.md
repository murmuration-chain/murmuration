# Members

A member is a GitHub identity whose reviews count toward enacting changes (see
[GOVERNANCE.md](GOVERNANCE.md)). Anyone may open issues and pull requests; only members'
approvals count.

To join: open a pull request adding a row below with your GitHub handle and a one-line
introduction. It is admitted under the normal rule (2 member approvals).
